Privacy Policy

The ArchField GIS application respects user privacy and complies with Google Play requirements. This policy explains what data is collected and how it is used.

1. Data Collection

ArchField GIS may collect the following data:

  • Location data – precise GPS location (only when enabled by the user).
  • Camera images – photos of archaeological findings taken or uploaded by the user.
  • Gallery / storage access – selecting images for analysis and saving data locally.
  • Saved points and maps – archaeological points, coordinates, and offline maps stored locally on the device.

2. Use of Data

The collected data is used only for core functionality of the application:

  • Displaying user location on maps.
  • Saving archaeological findings with coordinates and images.
  • Providing offline map functionality.
  • Analyzing user-uploaded images using AI (Gemini API) to suggest matching 3D models.
  • Exporting user data (points and coordinates) to CSV for personal use.

3. AI Processing

The application uses Google Gemini API to process user-uploaded images. Images are sent securely to Google servers for analysis in order to identify and recommend relevant 3D models. These images are not used for any other purpose.

4. Data Storage

Most data is stored locally on the user's device. Images may be temporarily processed by third-party AI services (Google Gemini) during analysis. The application does not sell or misuse user data.

5. Third-Party Services

  • Google Gemini API – AI image analysis and model recommendations.
  • Mapsforge – map rendering.
  • OpenStreetMap – map data provider.
  • Google Play Services – location services.

6. Data Sharing

User images may be transmitted to Google Gemini API for processing. No personal data is sold or shared with unrelated third parties.

7. Security

All data transmissions are performed over secure connections (HTTPS). Local data remains on the device unless explicitly exported by the user.
