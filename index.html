Политика конфиденциальности

Приложение ArchField GIS заботится о конфиденциальности пользователей и соблюдает требования Google Play. Ниже указано, какие данные мы собираем и как их используем.

1. Сбор данных

ArchField GIS собирает следующие данные:

  • Геолокация – точное местоположение пользователя через GPS (только при включении GPS).
  • Камера – фото археологических находок для сохранения в приложении.
  • Галерея / хранилище – выбор изображений и сохранение данных локально.
  • Сохраненные точки и карты – данные о найденных объектах и офлайн-карты хранятся локально.

2. Использование данных

Данные используются исключительно для работы приложения:

  • Отображение текущего местоположения на карте.
  • Сохранение координат археологических находок и фото.
  • Работа с офлайн картами без интернета.
  • Экспорт данных (точки и координаты) в CSV для личного использования пользователем.

3. Хранение данных

Все данные хранятся локально на устройстве пользователя. Приложение не передает данные третьим лицам без явного согласия пользователя.

4. Сторонние сервисы

Приложение использует следующие сторонние сервисы:

  • Mapsforge – для отображения карт.
  • OpenStreetMap – данные карт.
  • Google Play Services – определение местоположения.

5. Передача данных

Все пользовательские данные, если передаются (например, для загрузки карт по URL), шифруются и используются только для работы приложения. Личные фотографии и координаты хранятся только локально, пока пользователь их не экспортирует в CSV.
